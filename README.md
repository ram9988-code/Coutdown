## 📖 Overview

**Chronos** is not just another countdown app or habit tracker. It is an existential operating system designed to instill radical urgency, clarity, and relentless focus into everyday life. 

By combining the timeless wisdom of Stoic *Memento Mori* (remember you must die) with modern chronobiology and ultradian performance workflows, Chronos transforms abstract time into a tactile, inescapable reality.

Built from the ground up with a strict **Monochromatic Obsidian Aesthetic**, mechanical **Split-Flap Digit Animations**, **Zero-Telemetry Offline Architecture**, and **Biometric App Locking**, Chronos serves as your perpetual desk or pocket memento mori.

## ⚡ Core Pillars & Key Features

### 1. Countdowns & Mortality Engine (`/`)
* **Lifespan Countdown (Memento Mori)**: Computes your exact biological time remaining on Earth down to the second based on your birthdate and actuarial lifespan expectancy. Displays real-time life percentage elapsed with a precision progress gauge.
* **Master Success Goal**: Pinpoint your single highest-leverage life milestone with an active deadline, vision anchor, and start-to-finish timeline progress bar.
* **Categorized Event Countdowns**: Create, organize, and pin countdowns across 5 dedicated categories:
  * 🎯 `Milestone` — Major achievements and career leaps
  * 🚀 `Project` — Sprints, launches, and ship dates
  * 📅 `Event` — Conferences, gatherings, and key moments
  * 🔄 `Habit` — Day-count resets and streak horizons
  * 👤 `Personal` — Private commitments and anniversaries
* **Split-Flap Mechanical Digit Displays**: Custom-built 3D mechanical flip animation (`AnimatedDigit`) inspired by vintage transit flip-clocks with dampening physics and spring recoil.
* **Instant Filtering & Quick Pinning**: Pin your top-priority deadlines directly to the top of your stack and filter by category with zero friction.

### 2. Perspective & Existential Horizons (`/explore`)
* **Multi-Horizon Cadence Tickers**: Live second-by-second tracking of your progression through the current **Minute**, **Hour**, **Day**, **Week**, and **Year**.
* **Visual Matrices of Time**:
  * **52-Week Year Matrix**: Interactive grid visualizing all 52 weeks of the current year (past weeks, current active week, and remaining weeks).
  * **24-Hour Diurnal Matrix**: 24-block visual matrix indicating how much of today has burned away.
  * **Lifetime Grid**: Macro perspective showing decades and years lived vs. remaining.
* **Vitality Live Stream**:
  * 💓 **Estimated Heartbeats Remaining**: Dynamically ticking down your remaining lifetime heartbeats at rest (~80 bpm).
  * 🫁 **Estimated Breaths Remaining**: Real-time ticker of remaining respiratory cycles (~16 bpm).
  * ☀️ **Waking Life vs. Sleep**: Explicit breakdown of waking hours left vs. hours spent asleep (assuming 8h restorative rest per day).
  * 🏖️ **Remaining Summers & Weekends**: Exact count of warm seasons and weekend breaks left in your projected lifetime.
* **Personality Wisdom & Historical Quests**: Curated wisdom, philosophies, and actionable daily quests from history's most disciplined minds across 5 archetypes:
  * 🛡️ *Stoic* (Marcus Aurelius, Seneca, Epictetus)
  * 💡 *Innovator* (Steve Jobs, Nikola Tesla)
  * 🎨 *Polymath* (Leonardo da Vinci, Benjamin Franklin)
  * 🏛️ *Philosopher* (Friedrich Nietzsche, Socrates)
  * ⚔️ *Strategist* (Sun Tzu, Alexander the Great, Miyamoto Musashi)
* **Procedural Clock Escapement (Audio)**: Built-in analog ticking synthesizer utilizing the Web Audio API to produce subtle, tactile sine/frequency-ramped tick-tock impulses with zero external MP3 assets.

### 3. Tracker & Execution Matrix (`/tracker`)
* **Daily Discipline & Habit Stacking**: Pre-configured with four foundational non-negotiables:
  * ⚡ **90m Deep Work Block** (High-leverage distraction-free execution)
  * 🏋️ **Physical Movement & Training** (45+ mins strength, cardio, or mobility)
  * 🍃 **Mindful Solitude & Walk** (15 mins nature/silence without screens)
  * 🌙 **Sleep Before 11:00 PM** (Circadian alignment & recovery)
  * *Supports adding custom habits with dedicated icons and sub-goals.*
* **Streak Tracking Engine**: Computes daily completions, current consecutive-day streak, all-time best streak, streak reset warnings, and visual 7-day retrospective history chips.
* **Circadian Bio-Rhythm Flow Engine**: Tracks your natural biological clock throughout the day across 6 circadian windows:
  * `06:00 – 09:00`: Dawn Awakening & Fasted Focus (cortisol surge & priority mapping)
  * `09:00 – 13:00`: Deep Cognitive Prime (peak neuroplasticity & uninterrupted execution)
  * `13:00 – 15:00`: Metabolic Recharge & Pause (digestive lull, walking, light tasks)
  * `15:00 – 19:00`: Second Flow Wave & Execution (creative brainstorming & physical training)
  * `19:00 – 22:00`: Twilight Wind-Down (digital sunset, reading, parasympathetic calm)
  * `22:00 – 06:00`: Cellular Restoration & Sleep (glymphatic clearance & tissue recovery)
* **Ultradian Focus Timer**: Integrated high-performance timer supporting three scientifically calibrated block durations:
  * ⏱️ **25m Sprint** (Classic Pomodoro burst)
  * 🌊 **50m Deep Flow** (Extended cognitive block)
  * 🚀 **90m Ultradian Rhythm** (Maximal human focus session before recovery)
* **Earth Milestones**: Ticker celebrating your total continuous days alive on Earth alongside an exact countdown to your next birthday orbit.

### 4. Fortified Privacy & Device Security (`src/features/security`)
* **Biometric Authentication**: Native integration with Apple Face ID / Touch ID and Android Biometrics / Fingerprint sensors via `expo-local-authentication`.
* **Master PIN Protection**: 4-digit master PIN keypad lock screen for devices without biometrics or as an administrative fallback.
* **App Lifecycle Auto-Lock**: Automatically locks Chronos whenever the app enters background or the device screen turns off.
* **Keep-Awake Desk Mode**: Integrated `expo-keep-awake` toggle allowing the app to stay continuously lit on a desk stand or bedside dock.
* **100% Offline-First**: Zero external servers, zero analytic trackers, zero third-party telemetry. All records reside exclusively in encrypted local `AsyncStorage`.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed on your machine:
* [Node.js](https://nodejs.org/) (version **18.x** or higher, LTS recommended)
* [pnpm](https://pnpm.io/) or `npm`
* [Git](https://git-scm.com/)
* [Expo Go](https://expo.dev/go) app on your physical iOS or Android device (for rapid testing), or Xcode / Android Studio for emulator execution.

### Installation

1. **Clone the repository**:
   ```bash
   git clone git@github.com:ram9988-code/Coutdown.git
   cd Coutdown
   ```

2. **Install dependencies**:
   ```bash
   pnpm install
   # or
   npm install
   ```

3. **Start the development server**:
   ```bash
   pnpm start
   # or
   npx expo start
   ```

## 📱 Running on Platforms

Once the Expo interactive development menu appears in your terminal:

### Physical Device (Fastest)
* Scan the QR code displayed in the terminal using the **Camera app** (iOS) or the **Expo Go app** (Android).

### Android Emulator
* Press `a` in the terminal, or run:
  ```bash
  pnpm run android
  ```

### iOS Simulator (macOS only)
* Press `i` in the terminal, or run:
  ```bash
  pnpm run ios
  ```

### Web Browser
* Press `w` in the terminal, or run:
  ```bash
  pnpm run web
  ```

## 📦 Building for Production (EAS Build)

Chronos is pre-configured with `eas.json` for building release APKs, Android App Bundles (AAB), and iOS binaries.

1. Install the EAS CLI globally:
   ```bash
   npm install -g eas-cli
   ```

2. Log in to your Expo account:
   ```bash
   eas login
   ```

3. Build for Android (Standalone APK for distribution or testing):
   ```bash
   eas build --platform android --profile preview
   ```

4. Build for Production (Play Store / App Store):
   ```bash
   eas build --platform all --profile production
   ```

## 🔒 Security & Privacy Guarantees

Chronos was engineered under the strict principle of **Personal Data Sovereignty**:

1. **Zero External Network Requests**: The app functions 100% offline. No analytics, tracking pixels, or remote database syncs.
2. **Local Biometric Validation**: Biometric checks execute directly against the secure hardware enclave on your device (`LocalAuthentication`).
3. **Encrypted Key-Value Persistence**: All profile data (birthdates, goals, habit streaks, custom countdowns) is stored solely in on-device storage.
4. **Resilient Background Defense**: Resuming the app from background automatically triggers the security overlay if biometric or PIN protection is enabled.
